## Prompt

/sp.constitution

1. Identity & Scope
Project Name: Phase I: Todo In-Memory Python Console App.

Mission: Build a strictly CLI-based task manager to master the Spec-Driven Development (SDD) workflow.

Constraint: Implement ONLY Basic Level features. Do not implement web interfaces, AI agents, or database persistence.

2. Technical Non-Negotiables
Language: Python 3.13+.

Tooling: Managed via uv. No external database drivers allowed.

Data Persistence: Strictly In-Memory. Data is held in Python data structures (Lists/Dictionaries) and will clear upon exit.

Typing: Mandatory use of typing module (Type Hints) for all function signatures.

3. Phase I Functional Requirements (Strict)
The implementation must fulfill exactly these 5 pillars:

Add Task: Store a title (required) and description (optional).

Delete Task: Remove a task using its unique integer ID.

Update Task: Modify the title or description of an existing task ID.

View Task List: Display all tasks with their IDs and a clear status indicator.

Mark as Complete: Toggle status between "Pending" and "Complete."

4. Architectural Guardrails
Clean CLI: Output must be formatted for readability (e.g., status symbols [ ] and [X]).

Separation of Concerns: Keep the TaskManager class (logic) separate from the cli_loop (IO).

Error Handling: Must handle ValueError for non-integer ID inputs and IndexError/KeyError for missing IDs.

5. SDD Workflow Rule
Reference Mandatory: Every function generated by Claude Code must include a docstring comment referencing the speckit.tasks ID it satisfies.
